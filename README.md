# 師大附中｜數位化線上填寫行政表單系統（Word 專用試用版 V3.3）

四種行政表單：校外教學參觀活動、教師請假課務處理、外賓臨時停車、入校申請。

- 目前只輸出可編輯 Word（.docx）；PDF 功能已暫時移除。
- 網頁全程在瀏覽器內運作，不上傳表單資料到伺服器；沒有登入、伺服器資料庫或自動儲存。
- 使用者可手動下載 JSON 草稿，並在下次重新載入。公用電腦須自行清除下載的草稿。
- 維持原 Word 表格和簽名欄；文字預設標楷體，建議在裝有標楷體的 Windows 電腦版 Word 使用。
- 右側 canvas 是位置示意圖；正式文件以 Word 下載檔為準。
- 已連結：https://hsnu-campus-map.vercel.app/

## 免費發布

1. 在 GitHub 建立公開 repo（請先確認空白學校表單允許公開）。
2. 將此資料夾內的 `index.html` 與 `README.md` 上傳 repo 根目錄。
3. 在 Settings > Pages 選 Deploy from a branch，分支 main / root；GitHub Pages 會提供網址。
4. 不需資料庫及付費主機；GitHub 免費服務有自己的使用條款和限制。

**注意：** 本版仍為試用版。請正式使用前由相關行政單位核對輸出的頁面內容與請假時數規則。
