## 實際產生及渲染

透過 Chromium / Playwright 操作網頁欄位及下載按鈕，取得實際 DOCX，再以 LibreOfficeDev 26.8 轉成內部驗收 PDF 並渲染 PNG；已目視檢查全頁。沒有新增網站 PDF 下載功能。

| 欄位 | 驗收結果 |
| --- | --- |
| 班級、科目 | 各欄水平置中，直排，不貼左線 |

| 長文字 | 班級/科目/教師 12 字、地點 36 字、課表 18 字、其他說明 20 字，目視無溢出或新增重疊 |
| 可編輯與頁數 | 保留原文字框及 18 個 Word 表格；一般/長文字均單頁，渲染 PDF 的影像物件數為 0 |

## 回歸檢查

`check_fieldtrip_word.py` 已通過：實際 UI 下載、左右內容一致、簽名留白、原紙張尺寸、所有目的、00/23 整點、長文字、草稿儲存與載入、校園地圖連結、非本次範圍原始碼完全一致。教師請假、外賓停車、入校三種 DOCX 分別以修改前後頁面下載，其 ZIP 內所有檔案內容逐一相同。

重現方式（Python 需安裝 playwright、lxml）：

```sh
python tests/check_fieldtrip_word.py --browser /usr/bin/chromium --output-dir work/fieldtrip-check --baseline-ref main
```

將輸出的 template.docx、sample.docx、purpose-6.docx 以 Word 或 LibreOffice 渲染，對照上述圖檔。PDF 僅用於本地驗收，不提供網站下載。
